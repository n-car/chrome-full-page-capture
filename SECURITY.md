# Sicurezza

## Versioni supportate

È supportata l'ultima versione pubblicata. Prima di segnalare un problema, verifica se è ancora presente sul branch `main`.

## Segnalare una vulnerabilità

Non aprire una issue pubblica per vulnerabilità, credenziali o contenuti sensibili. Usa **Security → Advisories → New draft security advisory** nel repository per inviare una segnalazione privata:

https://github.com/n-car/chrome-full-page-capture/security/advisories/new

Indica la versione dell'estensione e di Chrome, il sistema operativo, i passaggi minimi per riprodurre il problema e l'impatto previsto. Rimuovi dai materiali pagine, screenshot, token e dati personali non indispensabili.

Riceverai una conferma appena la segnalazione sarà esaminata. Correzione e divulgazione verranno coordinate in base a gravità e riproducibilità; il progetto non offre attualmente un bug bounty.
